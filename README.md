# Heart_disease
# پیش‌بینی بیماری قلبی با استفاده از ماشین لرنینگ

## توضیحات پروژه

این پروژه یک مدل یادگیری ماشین ساده برای **پیش‌بینی احتمال ابتلا به بیماری قلبی** بر اساس ویژگی‌های پزشکی افراد است. مدل با استفاده از الگوریتم **Logistic Regression** آموزش دیده و دقت مناسبی روی داده‌های تست دارد.

داده‌ها از دیتاست معروف **Heart Disease UCI** (موجود در Kaggle/UCI) استفاده شده که شامل ۳۰۳ نمونه است.

> **توجه بسیار مهم**: این مدل صرفاً برای اهداف آموزشی ساخته شده و **به هیچ عنوان نباید به عنوان ابزار تشخیص پزشکی** استفاده شود. تشخیص بیماری قلبی حتماً باید توسط پزشک متخصص انجام شود.

## ویژگی‌های دیتاست

دیتاست شامل ۱۳ ویژگی ورودی و یک ستون هدف (target) است:

| ویژگی             | توضیحات                                                                 |
|-------------------|-------------------------------------------------------------------------|
| age               | سن بیمار                                                               |
| sex               | جنسیت (۱ = مرد، ۰ = زن)                                                |
| cp                | نوع درد قفسه سینه (۰–۳)                                                |
| trestbps          | فشار خون در حالت استراحت (mm Hg)                                       |
| chol              | کلسترول سرم (mg/dl)                                                    |
| fbs               | قند خون ناشتا > ۱۲۰ mg/dl (۱ = درست، ۰ = نادرست)                       |
| restecg           | نتایج الکتروکاردیوگرام در حالت استراحت (۰–۲)                          |
| thalach           | حداکثر ضربان قلب достиг‌شده                                           |
| exang             | آنژین ناشی از ورزش (۱ = بله، ۰ = خیر)                                  |
| oldpeak           | کاهش قطعه ST ناشی از ورزش نسبت به استراحت                              |
| slope             | شیب قطعه ST در اوج ورزش (۰–۲)                                           |
| ca                | تعداد رگ‌های اصلی رنگ‌شده با فلوروسکوپی (۰–۳)                         |
| thal              | نتیجه تست تالیوم (۳ = نرمال، ۶ = نقص ثابت، ۷ = نقص قابل برگشت)          |
| target            | خروجی: ۱ = وجود بیماری قلبی، ۰ = سالم                                 |

## دقت مدل

- دقت روی داده‌های آموزشی: **~۸۵.۵٪**
- دقت روی داده‌های تست: **~۸۳.۶٪**

(دقت ممکن است بسته به random_state کمی متفاوت باشد)

## فایل‌های پروژه

- `heart_disease_model.py`: اسکریپت اصلی (بارگذاری داده، آموزش مدل، ارزیابی، ذخیره مدل با pickle و مثال پیش‌بینی)
- `heart.csv`: فایل دیتاست (باید در کنار اسکریپت قرار گیرد)
- `heart_disease_model.sav`: فایل مدل آموزش‌دیده ذخیره‌شده

## نحوه اجرا

۱. کتابخانه‌های مورد نیاز را نصب کنید:

```bash
pip install numpy pandas scikit-learn
```

۲. فایل `heart.csv` را از [اینجا](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset) یا [UCI](https://archive.ics.uci.edu/ml/datasets/heart+disease) دانلود کنید و در همان پوشه قرار دهید.

۳. اسکریپت را اجرا کنید:

```bash
python heart_disease_model.py
```

اسکریپت مدل را آموزش می‌دهد، دقت را نمایش می‌دهد و یک مثال پیش‌بینی انجام می‌دهد.

### مثال پیش‌بینی با مدل ذخیره‌شده

```python
import pickle
import numpy as np

# بارگذاری مدل
loaded_model = pickle.load(open('heart_disease_model.sav', 'rb'))

# داده ورودی نمونه (به ترتیب ویژگی‌ها)
input_data = (62, 0, 0, 140, 268, 0, 0, 160, 0, 3.6, 0, 2, 2)

input_data_reshaped = np.asarray(input_data).reshape(1, -1)

prediction = loaded_model.predict(input_data_reshaped)

if prediction[0] == 0:
    print('فرد سالم است و بیماری قلبی ندارد')
else:
    print('فرد مبتلا به بیماری قلبی است')
```
